## Plan-introduced decisions

- Reset or a scenario choice during a running turn is allowed (not 409): the old session is closed, its worker keeps running its model and tool calls against the mock in the background, and its result is discarded; a waiting payment is declined (Task 3).
- Exit words (`quit`, `exit`) are ordinary messages in the web console, not session-ending (Task 3).
- An answered payment card stays in the chat, collapsed to one status line ("Payment details sent" / "Payment cancelled" / "Payment request expired") (Task 3, Task 6).
- A failed reservation read when choosing a scenario returns HTTP 502 with the session already reset, and the page shows the error above the composer (Task 4, Task 6).
